## Description
Hastaは、楽しみにしている日までの日数をカウントダウンし、いつでも目に入る場所に表示します。ロック画面、ホーム画面、そしてスタンバイに。

カウントダウンの作成はほんの数秒。日付を選んで名前を付け、シンボルと色を選ぶだけで、あとはHastaにおまかせ。

無料、しかも制限なし
• カウントダウンは無制限
• すべてのウィジェットサイズに対応：ホーム画面の小・中・大、ロック画面の円形・長方形・インライン
• 自動モードで、年・月・週・日・時間・分の中から最適な単位で表示
• 当日は秒単位のライブカウントダウン
• イベントごとにリマインダーを自由に設定：1週間前、前日、1時間前など、好きなタイミングで
• 誕生日、記念日、祝日などの繰り返しイベント
• 過去のイベントからの経過日数もカウント
• iCloud同期で、すべてのデバイスにカウントダウンを同期。新しいiPhoneにも復元できます
• 数百種類のシンボルと、厳選されたカラーパレット
• ライトモードでもダークモードでも美しく

HASTA PREMIUM
1回だけの小さな買い切り。サブスクリプションは一切ありません。
• 写真の背景（位置とズームを調整可能）
• Live Photoエフェクト：好きなフレームを選んだり、長時間露光を作成したり
• 追加の書体とウィジェットスタイル
• カスタムカラー
• 代替アプリアイコン
• 個人デベロッパを応援

プライバシーを第一に
アカウント登録、広告、トラッキングは一切なし。カウントダウンはお使いのデバイスと、あなただけが見られるプライベートなiCloudアカウントに保存されます。
