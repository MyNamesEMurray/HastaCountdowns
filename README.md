# Hasta

Countdown widgets for the iPhone Home Screen and Lock Screen. Free to use, with a one-time Hasta Premium unlock.

## Requirements

- Xcode 26 or later
- iOS 18.0 or later

## Getting Started

1. Open `Hasta.xcodeproj`.
2. Select the **Hasta** target, open **Signing & Capabilities**, and choose your team. Repeat for the **HastaWidgets** target.
3. Pick an iPhone simulator or device and run the **Hasta** scheme. Press ⌘U to run the tests.

The scheme uses `Hasta.storekit` so the Premium purchase can be tested locally without App Store Connect. To test against the sandbox instead, edit the scheme and set **StoreKit Configuration** to None.

## Project Layout

| Folder | Contents |
|---|---|
| `App/` | The iOS app: screens, purchase manager, reminders, assets |
| `Widgets/` | WidgetKit extension: Countdown and Up Next widgets |
| `Shared/` | Code compiled into both targets: model, date math, storage, widget views, App Intents |
| `Tests/` | Swift Testing unit tests for the date math and premium gating |
| `AppStore/` | App Store Connect metadata |
| `scripts/` | Project and icon generators |

The app and widget share data through the App Group `group.com.exaltedpixels.Hasta`. Countdowns are stored as JSON in the group container, and photo backgrounds are stored as downscaled JPEGs alongside them.

## Free vs Premium

| Free | Premium |
|---|---|
| Unlimited countdowns | Photo backgrounds |
| Every widget size | Serif, Mono and Condensed typefaces |
| Repeating events, count up | Vivid and Night widget styles |
| Days, weeks or months | Custom colors |
| Reminders | Alternate app icons |
| Rounded and Standard typefaces, Classic and Minimal styles | |

Premium is the non-consumable product `com.exaltedpixels.Hasta.premium`. The unlocked state is cached in the App Group so widgets can respect it.

## Regenerating the Project

`Hasta.xcodeproj` is generated by `scripts/generate_project.rb` (requires the `xcodeproj` gem). Files added in Xcode work normally; only rerun the script if you prefer to manage the project from the command line, since it overwrites the project file.

App icons are placeholders generated by `scripts/generate_icons.py`. Replace the PNGs in `App/Assets.xcassets` with final artwork.
