# Hasta

Countdown widgets for the iPhone Home Screen and Lock Screen. Free to use, with a one-time Hasta Premium unlock.

## Building

There is no Mac in the loop: GitHub Actions builds everything. `Hasta.xcodeproj` is generated from `project.yml` by [XcodeGen](https://github.com/yonaskolb/XcodeGen) on every run and is not committed.

| Workflow | Runs on | What it does |
|---|---|---|
| **Build** | every push to a branch other than `main`, or manually | Compiles the app, widget and tests for the iOS Simulator and runs the tests |
| **TestFlight** | manually from the Actions tab, or when a release is published | Archives, signs, verifies the App Group entitlement, and uploads to TestFlight |

### TestFlight setup

Add these repository secrets under **Settings > Secrets and variables > Actions**. They can use the same App Store Connect API key as LensLink.

| Secret | Value |
|---|---|
| `APP_STORE_CONNECT_KEY_ID` | the API key's Key ID |
| `APP_STORE_CONNECT_ISSUER_ID` | the Issuer ID |
| `APP_STORE_CONNECT_KEY_P8` | the full contents of the `.p8` file |
| `APPLE_TEAM_ID` | your 10-character Team ID |

Then run **Actions > TestFlight > Run workflow**. Build numbers come from App Store Connect, and the version comes from the `version` input or the release tag (`v1.0.1` becomes `1.0.1`), falling back to `project.yml`.

### Runner

Both workflows use GitHub's `macos-26` runner. To use a different runner, set the repository variable `MACOS_RUNNER` to its label. To pin an Xcode version, set `XCODE_VERSION` to a major version such as `27`. Otherwise the newest release Xcode on the runner is used.

## Project Layout

| Folder | Contents |
|---|---|
| `App/` | The iOS app: screens, purchase manager, reminders, assets |
| `Widgets/` | WidgetKit extension: Countdown and Up Next widgets |
| `Shared/` | Code compiled into both targets: model, date math, storage, widget views, App Intents |
| `Tests/` | Swift Testing unit tests for the date math and premium gating |
| `AppStore/` | App Store Connect metadata |
| `site/` | Website for hasta.day |
| `scripts/` | Icon generator |
| `.github/` | CI workflows and helper scripts |

The app and widget share data through the App Group `group.com.exaltedpixels.Hasta`. Countdowns are stored as JSON in the group container, and photo backgrounds are stored as downscaled JPEGs alongside them.

## Free vs Premium

| Free | Premium |
|---|---|
| Unlimited countdowns | Photo backgrounds |
| Every widget size | Serif, Mono and Condensed typefaces |
| Repeating events, count up | Vivid and Night widget styles |
| Days, weeks or months | Custom colors |
| Reminders | Alternate app icons |
| Rounded and Standard typefaces, Classic and Minimal styles | |

Premium is the non-consumable product `com.exaltedpixels.Hasta.premium`. The unlocked state is cached in the App Group so widgets can respect it.

## Website

`site/` is the static website for [hasta.day](https://hasta.day): the landing page, `privacy/`, and `support/`. It's plain HTML and CSS with no build step, deployed by Cloudflare Pages with the build output directory set to `site`. `site/_headers` sets security and cache headers.

## App Icons

App icons are placeholders generated by `scripts/generate_icons.py`. Replace the PNGs in `App/Assets.xcassets` with final artwork.
